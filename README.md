# Transcription

Репозиторий приложения **Транскрибация** (macOS): видео → текст через Whisper.

- Исходники: [`whisper-transcriber/`](whisper-transcriber/)
- Установщик: скачайте **`Транскрибация.dmg`** из [Releases](https://github.com/Ovchinin/Transcription/releases) (или artifact workflow **Build macOS DMG**)
- Установка: открыть DMG → перетащить в Applications → запуск по иконке (можно на рабочий стол)
- Без публикации в App Store

> Если репозиторий ещё называется `Ovchinin.github.io`, переименуйте его в **Transcription** в GitHub → Settings → General → Repository name.
